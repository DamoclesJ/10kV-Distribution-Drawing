# 10kV 配电工作票附图绘制软件 MVP 需求

## 1. 文档目的

本文档定义第一阶段 MVP 的正式范围基线，用于约束架构设计、开发排期和验收。凡未列入“必须实现”的能力，不自动视为 MVP 交付内容；后续如需纳入，应先更新本文件及实施计划。

本阶段产品形态为 Windows 桌面应用，面向 10kV 配电工作票附图的人工绘制、编辑、保存和输出，不承担电气计算或仿真职责。

## 2. MVP 必须实现

### 2.1 设备

| 设备类别 | MVP 要求 | 详细设计依据 |
| --- | --- | --- |
| 普通环网柜 | 可放置、编辑和显示；支持柜内开关状态修改 | `docs/ring-cabinet-design.md` |
| 一二次融合环网柜 | 可放置、编辑和显示；支持柜内隔离刀闸、断路器、接地刀闸状态独立修改 | `docs/ring-cabinet-design.md` |
| 电缆 | 可连接设备端子，支持选择、移动关联更新和属性编辑 | `docs/architecture.md`、`docs/drawing-rule.md` |
| 水泥杆 | 可放置、移动和编辑杆号等属性 | `docs/architecture.md`、`docs/drawing-rule.md` |
| 架空线路 | 可连接相关设备或杆位，支持选择、移动关联更新和属性编辑 | `docs/architecture.md`、`docs/drawing-rule.md` |
| 柱上设备 | 可放置在架空线路场景中，支持适用的属性编辑与开关状态修改 | `docs/architecture.md`、`docs/drawing-rule.md` |

柱上设备的首批图元以现有配电专业设计文档已经列出的设备为边界，包括柱上断路器、柱上负荷开关、柱上隔离开关和跌落式熔断器；不在 MVP 阶段自行增加其他柱上设备类型。

普通环网柜和一二次融合环网柜的柜型、间隔结构、内部设备及独立状态定义，以 `docs/ring-cabinet-design.md` 为准。PT 不是独立柜体；每个一二次融合环网柜必须包含一个 PT 特殊间隔及一个固定关联的 DTU 布局柜体。PT、DTU 均不作为设备库中的独立 MVP 设备类别，但其组合关系属于一二次融合环网柜设计的一部分。

### 2.2 编辑操作

#### 拖放

- 用户可从设备库将 MVP 设备拖放到画布。
- 放置后生成独立设备实例，具有唯一标识、位置和设备属性。
- 连接类图元应通过端子或合法连接点建立关系，不以屏幕坐标重合代替连接关系。

#### 移动

- 用户可移动画布中的设备实例。
- 设备移动后，与其端子相连的电缆或架空线路应刷新显示路径。
- 移动只改变布局，不自动改变设备类型、电气状态或连接语义。

#### 属性编辑

- 用户可选择设备并编辑该设备模型已定义的属性。
- 属性编辑至少覆盖图面识别所需的名称、编号或标注字段；具体字段以设备模型为准。
- 属性变更后，画布显示和保存数据应保持一致。

#### 状态修改

- 对具有开关状态的设备，用户可手动修改“拉开”或“合入”状态。
- 环网柜内各开关设备的状态必须独立保存和显示，不能用柜体单一状态替代。
- 不具有电气状态的设备不显示状态编辑入口。
- 状态修改仅改变工程数据和图面表达，不触发潮流计算或电气仿真。

#### 工作范围与工作地线

- 用户可人工指定由两个电气边界点定义的工作范围，并填写文字说明；工作范围不是普通矩形图形，也不由软件自动推导。
- 工作范围边界必须关联到明确的设备端子及其侧别。
- 用户可人工添加工作地线，指定连接端子、编号和备注，并在图面显示。
- 工作地线不得根据停电范围或拓扑自动生成；工作范围外及边界两侧的电气状态继续由用户人工确认。

### 2.3 输出

#### 保存工程

- 工程文件应保存在本地文件系统，不依赖数据库或云服务。
- 保存内容至少包括工程元数据、设备实例、设备属性、开关状态、端子连接关系、工作范围、工作地线和画布布局。
- 已保存工程应能重新打开并继续编辑；重新打开后，关键语义和图面布局应保持一致。

#### JPG 导出

- 可将完整工作票附图导出为 JPG 文件。
- 导出结果应包含画布中的设备、连接线、状态表达、工作范围、工作地线和文字标注。
- 导出结果应与打印输出采用同一绘制语义，避免状态或标注不一致。

#### 打印

- 可通过 Windows 打印体系输出完整附图。
- 打印结果应保持设备、连接、状态、颜色和文字标注的可辨识性。
- 打印属于图面输出，不要求生成可再次编辑的工程数据。

## 3. MVP 暂不实现

以下能力明确排除在第一阶段 MVP 之外：

- CAD DWG 兼容，包括导入、导出和双向转换。
- 自动计算潮流。
- 电气仿真。
- 自动停电分析。
- 自动生成工作地线或其他安全措施。
- 数据库。
- 云同步。
- 多用户协作。

上述排除项不应以预留完整业务模块、隐藏入口或未验收的试验功能形式进入 MVP。工程文件采用本地文件方案；设备状态和图面内容由用户编辑，不依赖计算或仿真结果自动生成。

## 4. MVP 验收边界

### 4.1 代表性绘制场景

至少使用下列两类工程完成端到端验收：

1. 普通环网柜经电缆连接至水泥杆上的电缆终端，再连接架空线路和柱上设备。
2. 一二次融合环网柜经电缆连接至水泥杆上的电缆终端，再连接架空线路和柱上设备。

验收工程应覆盖环网柜内部设备状态组合、至少一种柱上开关设备状态、工作范围边界、人工工作地线，以及设备和线路的文字属性。一二次融合环网柜场景应验证 PT 间隔及 DTU 跟随关系，但 PT、DTU 不作为设备库中的独立设备验收。

### 4.2 操作验收

- 所有 MVP 设备均可从设备库拖放到画布。
- 所有可布局设备均可移动，连接显示随端点位置更新。
- 设备属性可编辑、立即显示并被工程文件保存。
- 适用设备的状态可独立修改，保存后重新打开仍保持一致。
- 工作范围可通过两个端子边界人工定义，工作地线可人工添加、编号并保存；软件不自动生成安全措施。

### 4.3 输出验收

- 工程保存、关闭并重新打开后，设备、属性、状态、连接、工作范围、工作地线和布局一致。
- JPG 可正常打开，图面内容完整且状态、标注清晰。
- 可调用 Windows 打印流程并输出与画布语义一致的图面。

### 4.4 排除项验收

MVP 不提供 DWG、潮流、仿真、自动停电分析、自动生成工作地线、数据库、云同步和多用户相关入口或交付承诺。
