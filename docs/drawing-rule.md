# 配电专业附图绘图规则

> 文档状态：规范整理稿<br>
> 编制日期：2026-08-10<br>
> 规范来源：`reference/工作票及现场勘察附图绘制要求-汇总V7 (1).docx` 中“配电专业附图绘制要求”和“配电专业附图图元”<br>
> 适用范围：配电专业工作票附图、配电专业现场勘察附图

## 1. 整理边界

本文只整理规范中明确给出的配电专业要求，不包含输电、变电专业要求，也不增加规范未明确规定的颜色、线宽、字体、联锁、自动推导或版式规则。

规则分为两类：

- 工作票附图规则：适用于配电工作票附图。
- 现场勘察附图规则：适用于配电现场勘察附图。

两类附图要求不完全相同。软件应用规则时必须先确定文档类型，不能把现场勘察附图的要求无条件套用到工作票附图，也不能省略工作票对接地线编号等内容的要求。

## 2. 设备显示规则

### 2.1 工作票附图内容

| 规则编号 | 规范要求 |
| --- | --- |
| PD-WT-001 | 附图应绘制施工检修线路或设备所需停电部分和相关带电部分的单线图。 |
| PD-WT-002 | 应标明设备电压等级。 |
| PD-WT-003 | 应标明线路名称。 |
| PD-WT-004 | 应标明设备双重名称，且双重名称完整。 |
| PD-WT-005 | 应画出接地线装设位置和编号。 |
| PD-WT-006 | 接地刀闸应注明调度编号。 |
| PD-WT-007 | 应画出保留的带电部位，包括交叉、邻近、跨越、同杆塔带电线路和邻近带电设备。 |

### 2.2 工作票附图颜色

| 显示对象 | 颜色要求 |
| --- | --- |
| 带电部分 | 红色 |
| 停电部分 | 黑色或蓝色 |
| 文字标注 | 黑色或蓝色 |
| 接地点 | 黑色或蓝色 |

非彩色绘图打印后，应将带电部分用红笔描绘，以达到警示作用。

规范只明确了上述颜色类别，没有进一步规定具体色值、透明度、填充方式、线宽或灰度替代样式，本文不作扩展。

### 2.3 现场勘察附图内容

| 规则编号 | 规范要求 |
| --- | --- |
| PD-SR-001 | 勘察图应为勘察主要内容的示意图。 |
| PD-SR-002 | 应绘出工作全范围的接线方式。 |
| PD-SR-003 | 应标明线路名称。 |
| PD-SR-004 | 应标明站号、杆号。 |
| PD-SR-005 | 应绘出接地线位置。 |
| PD-SR-006 | 应绘出保留的带电部位，包括交叉、邻近、跨越、同杆塔带电线路和邻近带电设备。 |
| PD-SR-007 | 应绘出可能影响作业的周边环境，包括周边构筑物、易燃易爆设施、通信设施和交通设施等。 |

### 2.4 现场勘察附图颜色

| 显示对象 | 颜色要求 |
| --- | --- |
| 带电部分 | 红色 |
| 其他部分 | 黑色或蓝色 |

### 2.5 接地线显示

| 文档类型 | 位置 | 编号 |
| --- | --- | --- |
| 工作票附图 | 必须明确画出装设位置 | 必须填写；编号与工作票、现场编号一致 |
| 现场勘察附图 | 必须明确画出装设位置 | 不填写具体编号 |

工作接地线与接地刀闸是不同对象：规范要求工作票附图标出接地线装设位置和编号，同时要求接地刀闸注明调度编号。

## 3. 设备状态显示规则

### 3.1 配电图元表明确给出的状态

软件应使用配电专业图元表中对应的状态图元表示下列设备状态：

| 设备或对象 | 规范明确的状态 |
| --- | --- |
| 配电站内断路器 | 拉开、合入 |
| 配电站内负荷开关 | 拉开、合入 |
| 配电站内隔离开关 | 拉开、合入 |
| 配电站内熔断式负荷开关 | 拉开、合入 |
| 柱上断路器 | 拉开、合入 |
| 柱上负荷开关 | 拉开、合入 |
| 柱上隔离开关 | 拉开、合入 |
| 跌落式熔断器 | 拉开、合入 |
| 三工位断路器（上刀上接地） | 拉开位置、接地位置、运行位置 |
| 三工位断路器（下刀下接地） | 拉开位置、接地位置、运行位置 |
| 10kV 出线断路器间隔 | 运行位置、检修位置 |
| 设备状态 | 在运、拆除 |

状态显示必须采用相应的统一专业符号，不能仅用自由文字或任意自绘符号替代规范图元。

### 3.2 规范未明确状态集合的设备

配电图元表列出了下列对象的图元，但未在表中为其明确拉开/合入等状态集合：

- 熔断器。
- 配电变压器。
- 接地刀闸。
- 配电站用变。
- 站内电缆头。
- 电压互感器。
- 低压电缆分支箱。
- 架空变台、用户架空变台。
- 封闭母线、电缆、架空线路。
- 用户站、水泥杆。
- 电抗器、电力电容器、可调电容器、配电电容器。

对这些对象，本文只要求使用规范提供的对应图元，不自行增加规范状态。

环网柜模型中接地刀闸独立采用 `拉开/合入`，是一项已确认的产品模型要求，定义在 `docs/ring-cabinet-design.md`；由于 V7 配电图元表未明确列出接地刀闸的状态集合，本条不将其改写为 V7 规范规则。

### 3.3 状态与颜色的关系

规范分别规定了设备状态图元和带电/停电颜色，但没有给出根据开关状态自动计算带电范围的算法。因此：

- 设备状态应通过对应状态图元显示。
- 带电、停电部分应分别遵守红色、黑色或蓝色规则。
- 本文不规定由某一开关状态自动推导整张附图颜色的规则。

## 4. 工作范围绘制原则

### 4.1 工作票附图

| 规则编号 | 规范要求 |
| --- | --- |
| PD-WT-008 | 工作范围内的停电检修设备应全部画出。 |
| PD-WT-009 | 与停电检修设备有电气连接的设备应画到明显断开点。 |
| PD-WT-010 | 明显断开点以外的少部分应画出。 |
| PD-WT-011 | 经改造后电气连接发生变化的部分亦应画出。 |

工作范围绘制的边界以“停电检修设备—与其电气连接的设备—明显断开点—明显断开点外少部分”为规范给出的原则。规范未明确“少部分”的固定长度或设备数量，本文不设定数值。

### 4.2 现场勘察附图

现场勘察附图应绘出工作全范围的接线方式，并同时表达：

- 线路名称和站号、杆号。
- 接地线位置。
- 保留的带电部位。
- 可能影响作业的周边环境。

现场勘察附图可以手工绘制，也可以在一次系统接线图上进行标注。

### 4.3 更换和新增类工作的勘察图

配电专业典型现场附图部分明确：

- 更换类工作只在勘察记录附图中体现原设备。
- 新增类项目在勘察记录附图中需体现新设备。

## 5. 图元使用原则

### 5.1 统一专业符号

工作票附图中的现场各类设备必须使用统一的配电专业符号表示，并与标准票保持一致。不得用外观相似但语义不同的图元替代。

### 5.2 规范列出的配电图元

规范的配电专业图元表列出以下设备或对象：

| 类别 | 图元对象 |
| --- | --- |
| 配电站内开关设备 | 断路器、负荷开关、隔离开关、熔断式负荷开关、接地刀闸 |
| 柱上开关设备 | 柱上断路器、柱上负荷开关、柱上隔离开关、跌落式熔断器 |
| 变压及测量设备 | 配电变压器、配电站用变、电压互感器 |
| 线路与连接 | 站内电缆头、封闭母线、电缆、架空线路 |
| 站房及载体 | 低压电缆分支箱、架空变台、用户架空变台、用户站、水泥杆 |
| 三工位和间隔 | 三工位断路器（上刀上接地、下刀下接地）、10kV 出线断路器间隔 |
| 补偿及其他设备 | 熔断器、电抗器、电力电容器、可调电容器、配电电容器 |
| 状态标识 | 在运、拆除 |

### 5.3 图元与状态对应

- 设备类型必须选择对应的配电专业图元。
- 规范明确多个状态图元时，应使用与当前状态一致的图元。
- 三工位断路器应区分“上刀上接地”和“下刀下接地”两种设备形式，并使用各自对应图元。
- 10kV 出线断路器间隔应区分运行位置和检修位置。
- 在运、拆除状态应使用规范给出的状态表示。

## 6. 规则适用矩阵

| 规则内容 | 工作票附图 | 现场勘察附图 |
| --- | --- | --- |
| 停电部分和相关带电部分的单线图 | 是 | 以工作全范围接线方式表达 |
| 设备电压等级 | 是 | 规范本节未明确要求 |
| 线路名称 | 是 | 是 |
| 设备双重名称 | 是，且完整 | 规范本节未明确要求 |
| 接地线位置 | 是 | 是 |
| 接地线具体编号 | 是，且与工作票、现场一致 | 否 |
| 接地刀闸调度编号 | 是 | 规范本节未明确要求 |
| 保留带电部位 | 是 | 是 |
| 周边环境 | 规范本节未明确要求 | 是 |
| 带电部分红色 | 是 | 是 |
| 停电/其他部分黑色或蓝色 | 停电部分 | 其他部分 |
| 统一配电专业图元 | 是 | 规范本节未明确要求 |

表中“规范本节未明确要求”仅表示 V7 配电专业相应条款没有明确写出，不等同于禁止显示。

## 7. 本文不定义的内容

为避免扩展规范，本文不定义：

- 红色、黑色或蓝色的具体色值。
- 线宽、字体、字号、页面尺寸、图元间距和连接线路由。
- “明显断开点以外少部分”的固定距离或固定设备数量。
- 根据开关状态自动推导带电、停电范围的算法。
- 开关设备之间的联锁条件。
- 规范图元表以外的新设备符号。
- 输电、变电专业的绘图范围、颜色或图元规则。

若后续需定义上述内容，应有新的已确认需求或专业规范依据，并与本规范整理稿分开记录。

## 8. 软件模型映射说明

本节用于把规范要求映射到当前产品模型，不改变 V7 原文的规范边界：

- 工作范围使用 `WorkScope` 表达，由两个 `BoundaryPoint` 引用明确的 Device、Terminal 和 Side；画布范围框只作为可视化。
- 工作地线使用 `GroundingPoint` 表达，由用户人工选择连接端子并填写编号和备注；接地刀闸仍是独立开关设备。
- 软件不根据 WorkScope、开关状态或线路状态自动生成 GroundingPoint，也不自动判断停电范围。
- 架空线路画到某杆位后省略后续线路时，可使用线路继续符号和文字说明；延续部分状态由用户人工指定为带电或未知。
- 工作票附图中的 GroundingPoint 编号必须显示并校验；现场勘察附图只显示位置，不显示具体编号。
