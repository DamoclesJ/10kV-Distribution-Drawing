Main implementation is `502851c0ac4e21da1eec3a6d82fb8334b1b3a483`; Windows Fix-1 is `09e6e2d3c5648d9fea1e46ffb302e4bbbddb5c27`; Windows Fix-2 is `7307f1802ab8316f37020f563068390e10a470de`. 3. **Implementation Slice C — Route Continuity Stabilization — Closed / Accepted / Implemented / Windows Verified / Professionally Accepted:** implemented routing/runtime-internal `RouteFamilyKey`, transient continuity state independently scoped by `ConnectionId`, two-phase accepted-state publication, and hysteresis only among legal, sufficiently close route families. The calibrated 8 mm route-family switching margin yields stable legal route selection while higher-priority formal constraints, including `PreferredHorizontalY`, override hysteresis. Unrelated Transformer and CustomerStation professional body envelopes are hard routing obstacles; endpoint owners exclude their own obstacle by stable identity. The implementation preserves GAP / OHL required-waypoint behavior, group all-or-none publication, and final release publish before `EndGesture`. Clipboard integration closure adds deterministic bounded fallback for routing-invalid default placement, with atomic rollback, rematerialized retries, repeated-paste advancement, `PasteAt` isolation, and Copy reset. This remains obstacle-aware route selection, not generic drag-collision legality.
